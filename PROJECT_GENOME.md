# 🧬 Project Genome: CGAO Skills Landing

## 📌 Propósito
Landing page corporativa y portafolio de habilidades para el Centro de Gestión Agroempresarial del Oriente (CGAO) - Subsede Vélez, Regional Santander.

## 🛠️ Stack Técnico
- **Frontend:** Vanilla HTML5, CSS3 (Modern Glossy Design), JS (ES6+).
- **Despliegue:** Docker (Nginx Alpine).
- **Herramientas:** Python scripts para auditoría y SEO.

## 🚀 Estrategia de Escalabilidad
1.  **Componentización:** Migrar de un único `index.html` masivo a un generador de sitios estáticos o componentes Web (Web Components) si la complejidad aumenta.
2.  **Optimización de Activos:** Implementar Lazy Loading para imágenes y minificación automática vía scripts en `/scripts`.
3.  **SEO Dinámico:** Uso de metadata estructurada para mejorar el posicionamiento del CGAO.

## 📐 Patrones de Diseño
- **Mobile First:** Diseño responsivo garantizado.
- **Atomic Assets:** Estructura organizada de CSS y JS para evitar colisiones.

## 📂 Estructura DevBrain
- `/frontend`: Código fuente de la web.
- `/docs`: Guía de despliegue y manual de marca.
- `/maintenance`: Auditorías WCAG y logs de Docker.
- `/scripts`: Automatización y optimización.
