# Guía de apoyo para diseñar pruebas técnicas

> Orientación para instructores. Los rangos y ejemplos son propuestas de diseño; adáptelos al resultado de aprendizaje, a la especialidad y a las reglas vigentes de la sede.

## 1. Estructura modular sugerida

| Módulo | Enfoque | Rango sugerido |
| :--- | :--- | :---: |
| A | Fundamentos, análisis y planeación | 15–20 % |
| B | Construcción del producto o ejecución principal | 50–60 % |
| C | Eficiencia, calidad y comprobación | 10–15 % |
| D | Sostenibilidad, seguridad y cuidado de recursos | 5–10 % |

Elija valores que sumen el total acordado para la prueba. Estos rangos orientan el diseño; no son una distribución única para todas las especialidades.

## 2. Criterios M-J-P

- **M — Medición objetiva:** Defina una entrada, un resultado esperado y una forma de comprobarlos. Ejemplo: el subtotal coincide con cantidad por precio unitario.
- **J — Juicio técnico:** Use una escala común de 0 a 3 con descriptores observables. Ejemplo: 0 sin evidencia; 1 parcial; 2 cumple; 3 completo y fácil de seguir.
- **P — Proceso:** Evalúe acciones visibles de seguridad, orden y uso responsable de recursos. Limite el puntaje a lo que la persona puede controlar durante la prueba.

Como referencia para el ejemplo M-J-P de esta colección, M tiene al menos 60 puntos, J hasta 30 y P hasta 10. La rúbrica del reto de ADSO usa M=69, J=23 y P=8.

## 3. Sostenibilidad y seguridad

Incluya evidencias pertinentes a la actividad: separación de residuos según las instrucciones de la sede, cierre de programas y retiro seguro de archivos temporales, ergonomía, orden y uso de elementos de protección cuando correspondan. Si una prueba usa materiales físicos, defina cómo medirá sus mermas; no aplique metas genéricas sin una referencia para ese reto.

## 4. Revisión antes de aplicar

1. Pruebe el reto con una persona instructora y ajuste el tiempo según la dificultad real.
2. Compruebe que los puntajes sumen el total publicado y que la regla M-J-P se cumpla si se adopta.
3. Redacte instrucciones y límites con lenguaje directo.
4. Aplique la rúbrica a un caso de muestra y aclare las diferencias entre evaluadores.
5. Defina cómo se guardarán las evidencias de acuerdo con el procedimiento vigente de la sede.
